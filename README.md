# Noera — ονόματα σε 3D πάνω από πρόσωπα

[English below](#english)

**Έκδοση εφαρμογής:** v33 · **Άνοιγμα:** https://sidiropoulosag.github.io/ar-names/

Το **Noera** είναι εφαρμογή στο κινητό (PWA) που ανοίγει την κάμερα και, όταν αναγνωρίσει κάποιον που έχει καταχωριστεί, δείχνει το **όνομά του με τρισδιάστατα γράμματα** πάνω από το κεφάλι του — και μπορεί να δείχνει μήνυμα, αστείο 3D αντικείμενο ή φίλτρο. Δουλεύει για **πολλά πρόσωπα μαζί** στην οθόνη (έως 12).

Μπορεί να δουλέψει **μόνο στο κινητό σου** (τοπικά) ή **με οικογενειακό / ομαδικό server** που τρέχει ο διοργανωτής: τότε μοιράζεστε προφίλ, χαιρετισμούς, ομάδες και εκδηλώσεις. Το ίδιο link ανοίγει σε όλες τις συσκευές.

## Πώς το ανοίγω

1. Άνοιξε το link σε **Chrome (Android)** ή **Safari (iPhone, iOS 16.4+)**. Χρειάζεται **https** (ή localhost στον υπολογιστή).
2. Την πρώτη φορά διάλεξε **γλώσσα** (Ελληνικά / English / Français / Deutsch).
3. Ακολούθησε το σύντομο **καλώς ήρθες** (μπορείς να το παραλείψεις) και διάβασε για το απόρρητο.
4. Πάτα «📷 Άνοιγμα κάμερας» και δώσε άδεια κάμερας.
5. Προαιρετικά — **προσθήκη στην αρχική οθόνη** (ίδιο link παντού):
   - **Android (Chrome):** μενού ⋮ → «Εγκατάσταση εφαρμογής» ή «Προσθήκη στην αρχική οθόνη».
   - **iPhone (Safari):** Κοινοποίηση ⬆︎ → «Προσθήκη στην αρχική οθόνη».

Κουμπιά στην κύρια οθόνη: **👥** ρυθμίσεις, **🔄** αλλαγή μπροστινής/πίσω κάμερας, **⚪** στιγμιότυπο (κάμερα + ονόματα / 3D — στο κινητό ανοίγει η κοινοποίηση για αποθήκευση στη συλλογή).

## Καταχώριση προσώπου

Πάτα **«＋ Νέο άτομο»** (ή ακολούθησε τον οδηγό).

1. Γράψε **όνομα** (ελληνικά ή λατινικά).
2. Αν είσαι σε server: μπορεί να ζητηθεί **κωδικός πρόσκλησης** (ή ανοιχτή εγγραφή / κλειδί — ανάλογα με τις ρυθμίσεις του διαχειριστή). Προαιρετικά μήνυμα πάνω από το όνομα.
3. **«▶ Αυτόματη λήψη»**: κοίτα ευθεία και γύρνα λίγο το κεφάλι (πλάι / πάνω-κάτω). Εναλλακτικά «📸 Μία λήψη» ή «🖼️ Από φωτογραφία».
4. **«💾 Αποθήκευση»**. Στο server σου δείχνει **μία φορά** το προσωπικό token — κράτα αντίγραφο αν θες να συνδεθείς από άλλη συσκευή.

**Συμβουλές:** καλό φως στο πρόσωπο, χωρίς γυαλιά ηλίου/μάσκα, πρόσωπο περίπου στο 1/3 της οθόνης. Από Ρυθμίσεις → Άτομα μπορείς να προσθέσεις **«＋ λήψεις»** σε υπάρχον άτομο. Περίπου 1 λεπτό για την πρώτη φορά.

Σε **τοπική** λειτουργία τα άτομα μένουν μόνο σε αυτό το κινητό. Σε **server** καταχωρίζεις κυρίως **τον εαυτό σου** στο δίκτυο (☁️).

## Απόρρητο (όπως το λέει η εφαρμογή)

**Τι κρατιέται (με server οικογένειας), σύμφωνα με την πολιτική απορρήτου μέσα στην εφαρμογή:**
- το **όνομά σου** και ένα **αριθμητικό αποτύπωμα** προσώπου (σειρά αριθμών)· από αυτούς **δεν ξαναφτιάχνεται φωτογραφία**
- όσα διαλέγεις εσύ: μηνύματα, ποιος σε βλέπει, ομάδες
- οι φωτογραφίες εγγραφής χρησιμοποιούνται για τον υπολογισμό του αποτυπώματος· **η πολιτική λέει ότι ο οικογενειακός server δεν τις κρατά**

**Κατά την αναγνώριση στη λειτουργία server** στέλνεται μόνο το αριθμητικό αποτύπωμα (όχι η εικόνα της κάμερας) — αυτό γράφει και η σημείωση απορρήτου στην κύρια οθόνη.

**Μόνο στη συσκευή (χωρίς / εκτός server):** τα άτομα που προσθέτεις τοπικά μένουν στο κινητό (IndexedDB: αποτυπώματα + μικρή μικρογραφία για τη λίστα). Καμία εικόνα δεν φεύγει από το κινητό σε καθαρά τοπική λειτουργία.

**Διαγραφή:** Ρυθμίσεις → Απόρρητο και ασφάλεια → «Διαγραφή του προφίλ μου» — σβήνει προφίλ/αποτυπώματα/μηνύματα/ομάδες στον server και τα δεδομένα σε αυτό το κινητό.

**Αναφορά / αποκλεισμός:** από το φύλλο ατόμου μπορείς να αποκλείσεις (δεν βλέπεστε / δεν αναγνωρίζεστε / δεν στέλνετε μηνύματα) ή να αναφέρεις στον διαχειριστή. Οι αποκλεισμοί αναιρούνται από Απόρρητο.

Καταχώριζε **μόνο άτομα που συμφωνούν**.

## Σύνδεση με οικογενειακό / ομαδικό server

Χρειάζεται σύνδεση (και προφίλ στο δίκτυο) για κοινά προφίλ, μηνύματα/χαιρετισμούς μεταξύ συσκευών, ομάδες, εκδηλώσεις και πίνακα χαιρετισμών. Ο διαχειριστής τρέχει έναν server στο σπίτι / στον οργανισμό· **δεν** περιγράφουμε εδώ προσωπικές διευθύνσεις ή κλειδιά.

**Τρόποι εγγραφής νέων** (όπως τους λέει ο server στην εφαρμογή):
- **Ανοιχτή** — γράφεις όνομα και καταχωρίζεσαι
- **Με πρόσκληση** — κωδικός, σύνδεσμος ή QR (`?invite=…`)
- **Κλειστή** — δεν δέχεται νέες εγγραφές· μίλα με τον διαχειριστή

Παλιότερα / για διαχειριστή μπορεί να ζητηθεί **κλειδί πρόσβασης** (προχωρημένες ρυθμίσεις). Το **προσωπικό token** σου δίνεται μία φορά στην καταχώριση.

Χωρίς server (ή με άδεια διεύθυνση στις προχωρημένες): όλα γίνονται μόνο στη συσκευή.

## Ειλικρινή όρια

- Πλάγια: καλή αναγνώριση περίπου έως ±45°. Σε σχεδόν προφίλ (>~60°) συχνά ανιχνεύεται («?») αλλά δεν αναγνωρίζεται αξιόπιστα από την αρχή· αν ήδη έχει όνομα, μπορεί να μείνει όσο τον ακολουθεί η κάμερα.
- Μάσκες, γυαλιά ηλίου, πολύ χαμηλό φως, θόλωμα, πολύ μικρά/μακρινά πρόσωπα → αποτυχία ή «?».
- Μπορεί να γίνουν λάθη (συγγενείς που μοιάζουν κ.λπ.) — ρύθμισε την αυστηρότητα στα προχωρημένα.
- **Δεν είναι εργαλείο ταυτοποίησης / ασφαλείας.** Μόνο για οικογένεια, παρέα και διασκέδαση.
- Η ταχύτητα εξαρτάται από το κινητό. Για ομάδες σε απόσταση δοκίμασε «Εμβέλεια: Μακριά».

## Τεχνικά

### Pipeline (σύνοψη)
1. **Ανίχνευση** κάθε καρέ: YuNet (onnxruntime-web WASM) — πολλά πρόσωπα, 5 σημεία.
2. **Παρακολούθηση** (tracker): το όνομα «κολλάει» στο πρόσωπο όσο μένει στο κάδρο.
3. **Αναγνώριση** όταν χρειάζεται: SFace 128-d, σύριση με αποθηκευμένα αποτυπώματα (κατώφλι, περιθώριο 2ου καλύτερου).
4. **Σχεδίαση:** three.js — 3D κείμενο, αντικείμενα, φίλτρα· ορθογραφική επικάλυψη πάνω στην κάμερα.

# Noera — 3D name labels above recognised faces

**App version:** v33 · **Open:** https://sidiropoulosag.github.io/ar-names/

**Noera** is a phone PWA: point the camera at people who enrolled, and their **name appears as 3D lettering** above their head (optional message, 3D object, or funny filter). Up to **12 faces** at once.

It can run **on-device only**, or with a **family/group server** run by the organiser (shared profiles, greetings, groups, events). The **same link** works on every device.

---

## How to open

1. Open the link in **Chrome (Android)** or **Safari (iPhone, iOS 16.4+)**. Needs **https** (or localhost on a computer).
2. First launch: pick a **language** (Ελληνικά / English / Français / Deutsch).
3. Short **welcome** (skippable), then privacy notes.
4. Tap «📷 Open camera» and allow the camera.
5. Optional — **Add to Home Screen** (same URL everywhere):
   - **Android (Chrome):** ⋮ → Install app / Add to Home screen.
   - **iPhone (Safari):** Share ⬆︎ → Add to Home Screen.

Main UI: **👥** settings, **🔄** flip camera, **⚪** snapshot (frame + labels; share sheet on phones).

---

## First run

1. **Language** picker if none saved.
2. **Welcome** (3 steps): what it does · how to enrol · privacy. End with «Photograph me now» or «Just look first». Replay via Settings → Help → quick tour.
3. **Consent** before first enrolment (and once if the policy updated): read the **privacy policy**, tick agree, tap Agree.

---

## Enrolment

**「＋ New person」**

1. Enter a **name**.
2. On a server: may need an **invite code** (or open sign-up / access key — set by the admin). Optional message above your name.
3. **Auto capture** (turn your head), or one shot / from photo.
4. **Save**. On a server you see your **personal token once** — keep a copy for other devices.

Tips: good light, no sunglasses/mask, face ~⅓ of the frame. Add more shots later via People → 「＋ shots」.

**Local** people stay on this phone only. **Server** mode is mainly for enrolling **yourself** on the network.

---

## Camera screen

Recognised faces get a **3D name** (and optional message / object / filter). Tap someone to **greet or message** them (if they accept and visibility allows). First meeting may show a **「You met!」** card with share.

## Greetings, achievements, meet card, events

- **Greetings / messages:** tap a recognised person → emoji (e.g. 👋 ❤️ 😂 🎉 👍 and more) or short text. Same privacy/limits as messages; greet FX follows the same rules.
- **Achievements** (this device only): unlock quietly (e.g. 10/50 meets, 5/25 greets, emoji variety in a day, joined/created an event, tried a filter). Toast on unlock; list under My achievements.
- **「You met!」** card on first encounter, with date and share.
- **Events:** create → share **code**, **link**, or **QR**; others join by code or QR scan.
- **Greetings leaderboard:** optional **opt-in** only; can turn off; respects blocks.

## Privacy (as stated in the app)

**With a family server (privacy policy in-app):**
- your **name** and a numeric face **fingerprint** (numbers only — a photo cannot be rebuilt from them)
- what you choose: messages, who can see you, groups
- enrolment photos are used to compute the fingerprint; **the policy says the family server does not keep those photos**

**During recognition in server mode**, only the numeric fingerprint is sent (not the live camera image).

**On-device only:** local people stay in IndexedDB (embeddings + a small list thumbnail). In pure local mode no image leaves the phone.

**Delete:** Settings → Privacy → Delete my profile (server + this device). **Block / report** from a person’s sheet; unblock under Privacy.

Only enrol people who agree.

---

## Family / group server

Needed for shared profiles, cross-device messages/greets, groups, events, and the greetings board. The organiser runs a server; **this README does not publish personal server URLs or keys**.

**Sign-up modes** (from the app / server health):
- **Open** — name and enrol
- **Invite** — code, link, or QR
- **Closed** — no new sign-ups

Admins may use an access key (advanced). Your **personal token** is shown once at enrolment.

Empty/custom server URL in advanced settings → on-device only.

## Updates

From **v25** onward, app code is **network-first**: you get a new published version on the **first open** (no double open). If the page stays open during a publish, it reloads when safe or shows a small update bar. **Offline** uses the last cached version.

## Honest limits

- Solid recognition to about ±45° yaw; near-profile often detects but does not recognise from scratch; an existing label can persist while tracking.
- Masks, sunglasses, low light, blur, tiny/far faces → fail or 「?」.
- Mistakes happen (look-alikes) — tune strictness in Advanced.
- **Not a security or ID tool.**
- Performance depends on the phone; use Far range for distant groups.

## Technical

### Pipeline (short)
1. **Detect** every frame: YuNet via onnxruntime-web WASM.
2. **Track** faces so labels stick.
3. **Recognise** when needed: SFace 128-d vs stored embeddings.
